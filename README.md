# ArtRave / Atlas Sound

Рабочий музыкально-образовательный атлас Снежаны: маршруты слушания, история жанров и различение музыкальных влияний.

## Материалы

- [Музыкальный атлас](atlas/dj-luv-musical-atlas-v1.md) — расширенная карта жанров и контрольные пары для слушания.
- [Sound Atlas](atlas/dj-luv-sound-atlas.md) — вводные карточки жанров.
- [Единый маршрут](atlas/dj-luv-unified-sound-atlas.md) и [маршрут двух миров](atlas/dj-luv-two-worlds-route.md) — варианты учебной навигации.
- [PDF-сборка](atlas/dj-luv-sound-atlas-2026.pdf) — рабочий просмотр.

**Статус:** исследовательский и учебный черновик. Упоминания артистов и записей служат ориентирами для слушания; аудиофайлы и чужие обложки в репозиторий не добавлены. Документы о дипломной работе или постановке шоу здесь не представлены, поэтому они не заявлены как завершённые результаты.
